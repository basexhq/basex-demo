# BaseX — clickable preview

**Live at [demo.basex.com](https://demo.basex.com)** · not the real product yet · built in public.

BaseX is open price discovery for impact: anyone files a claim about real-world impact
(positive or negative), independent evaluators estimate its value, and a transparent,
challengeable consensus emerges. *Impact, honestly priced.*

This is a fully self-contained preview — one HTML file, sample data, zero dependencies,
real consensus math running in your browser. Every action explains itself.

Real talk: reality is multidimensional and resists convergence on a single number —
what is a tree worth twenty years from now? We acknowledge these constraints and push
forward anyway: discussing the best approach with partners, building in public.

Standing on shoulders — inspired by Bitcoin, Climate Coordination Network, Gitcoin,
Karma GAP, Giveth, Octant, and Artizen.
