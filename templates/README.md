# Starter templates — bring your data

**Any format works.** A spreadsheet, a PDF report, a link, a paragraph in an email,
a story told out loud. These templates are *starting points*, not requirements —
use one if a blank page feels hard, ignore them if you already have data.

| File | When to use it |
| --- | --- |
| [`claim.md`](claim.md) | You have one or a few claims and like writing in plain words. Fill in what you know, leave the rest blank. |
| [`claims.csv`](claims.csv) | You have many claims in a spreadsheet. Copy the header row, add your rows, send the file. |
| [`claim.json`](claim.json) | You are a developer or already have structured data. Mirrors the shape BaseX stores. |

## How to send it

- **Email:** email@genesis.re — attach anything, in any state of polish.
- **Pull request:** add a file under `data/` in the public repo. One record per file,
  so history stays readable and every change is visible.

## What happens next

1. We read it and reply — a human, within days, not a form.
2. Together we shape it into claims: who did what, when, which impact areas, your own
   estimate of the value (a range is great, negative impact is welcome too).
3. It lands on the demo with your name on it, as readable files with visible history.
   Nothing is hidden and nothing is edited silently — corrections are additive and signed.

Full walkthrough: [docs/onboarding.md](../docs/onboarding.md).
